# Surgical Coat Analyzer

用于小鼠背部单个手术区域左侧、中间、右侧毛色深度分析的本地工具。

Windows 用户可从 GitHub Releases 下载预先打包的 EXE；仓库本身只保存源码，不包含实验图片、SQLite 项目文件或导出结果。

软件使用用户标记的左、右边缘，在手术 ROI 内求解二维调和坐标。分界值（例如 40% 和 60%）对应调和坐标的等值线，因此能够随弯曲、扇环形区域平滑转向，不依赖固定的图片左右方向。

## 当前功能

- 递归读取 JPG、JPEG、PNG、TIFF、BMP 和 WebP，并处理 JPEG EXIF 旋转。
- 单个 `.sqlite` 文件保存项目、图片路径、实验组、标注、参数、复核状态和统计结果。
- 每张图片支持一个手术 ROI、一条连续左边缘链、一条连续右边缘链、多个排除区和一个灰卡区。
- 修改两个分界百分比后实时更新分界线与三个区域的颜色统计。
- 以 CIELAB `L*` 计算亮度，并报告 `100-L*` 形式的颜色深度、分位数及完整直方图。
- 界面可切换原始/灰卡校正结果；灰卡存在时按项目设定的标准 `L*` 做亮度归一化，同时保留原始结果。
- 独立定义白发和黑发的颜色深度范围，中间灰发范围可以不参与分类。
- 在原图上实时叠加黑白发遮罩，统计整体及左/中/右亚区面积。
- 批量勾选图片并分配到一个主实验组。
- 支持“项目统一分界值”和“每张图片各自分界值”两种最终导出模式。
- 导出区域汇总、中心加深指数、原始/校正直方图数据、逐图分布图、实验组平均分布图、参数清单和带标注的 PNG。
- 支持“低质量”和“无可识别手术区”，保留记录但排除最终统计。

## 源码运行

需要 Python 3.11 或 3.12。

```powershell
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
python -m coat_analyzer
```

也可以安装后双击 `run_source.bat`。应用只监听 `127.0.0.1`，浏览器中的图片和项目数据不会上传到网络。

## 仓库结构

- `src/coat_analyzer/`：分析、几何分区、SQLite 项目管理、导出和本地网页界面。
- `tests/`：分析、调和坐标、项目迁移和导出的回归测试。
- `packaging/`：Windows 打包启动器。
- `.github/workflows/tests.yml`：GitHub Actions 自动测试。

## 标注顺序

1. 新建项目并选择照片文件夹；SQLite 默认保存在该照片文件夹内。
2. 使用“手术区”工具逐点画 ROI，点击“闭合当前图形”。
3. 使用“左边缘”和“右边缘”工具，在 ROI 边界上单击或拖动，分别涂选两条连续边界链。
4. 必要时添加“排除区”和“灰卡”。
5. 调整两个分界百分比，确认分界线和颜色统计。
6. 保存草稿、确认并进入下一张，或标记质量状态。
7. 在“批量分组”页面建立实验组并勾选图片批量分配。
8. 在“项目与导出”中选择统一标准或逐图标准后导出。

重新画手术区会清除原左右边缘，因为边缘编号只对当前 ROI 有效。重新画灰卡会替换旧灰卡；排除区可以有多个。

## 导出文件

- `region_summary.csv`：每张图片 × 左/中/右区域的摘要指标。
- `lstar_histograms.csv`：兼容用的原始 `L*` 像素计数。
- `color_depth_histograms.csv`：以 0=白、100=黑表示的原始/灰卡校正相对频率。
- `center_darkening_index.csv`：中间区域相对于两侧平均值的加深指数。
- `hair_area_summary.csv`：黑发、白发及未分类像素在整体和各亚区中的面积与比例。
- `analysis_manifest.json`：项目标准、每张图状态及参数哈希。
- `annotated_images/`：ROI、左右边缘、排除区、灰卡及最终分界线叠加图。
- `histogram_plots/raw/individual/`：每张图片的左/中/右颜色深度分布图。
- `histogram_plots/raw/groups/`：实验组内逐图等权平均的分布图及 SEM。
- `histogram_plots/gray_corrected/`：仅对具有有效灰卡的图片生成相同结构的校正图。

导出结果默认写入待分析图片文件夹。实验组分布先对每张图片归一化，再按图片等权求平均，不会让面积较大的 ROI 获得更高统计权重。

原图不写入 SQLite，也不会移动或修改。移动原图文件夹后，项目将无法找到原始图片。
